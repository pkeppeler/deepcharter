Departure Mono 1.500 (departuremono-regular.otf)

The game's ttf font provider refuses this file ("Font is not in TTF format, was CFF"): Departure Mono is released only with CFF
outlines. textures/font/departuremono.png and font/terminal.json were therefore made from the .otf by tools/font_bitmap.py, which reads the file as data,
draws each glyph 7 pixels tall in capitals (the cap height of the game's own font), and writes a bitmap font. The .otf is not read by the
game. The font declares no Reserved Font Name. Regenerate with: python3 tools/font_bitmap.py

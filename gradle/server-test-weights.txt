# Server GameTest weights for -PgametestShard=i/n (gradle/gametest.gradle.kts): `<simple class name> <seconds>`.
# A batch runs its tests together, so no log line times one class; a class's seconds model its share of the suite's wall time instead,
# as the mean over the green `build` jobs 139658981252, 139702173341, 139713742475, 139727190604, 139763144735 and 139774806420
# (2026-11-26, #1327) of:
#   the server-thread time its tests held (`[slow-test] <test id> held the server thread <n> ms` lines; a test id starts with the class
#   name in snake case), plus
#   for each of its tests, its environment's time per test: the wall time of the environment's batches (from each `Running test
#   environment` line to the next) less the holds logged during them, over the environment's test count. Environments are
#   minecraft:default, each campaign environment, and the rest pooled.
# Rounded, at least 1 (the least the file accepts). The model sums to within 0.2 minutes of each job's measured suite time.
# A name is simple, or fully qualified when two classes share a simple name (the full name wins). A class not listed counts as 6 s,
# so a new class needs no entry; an entry for a class that no longer exists is ignored. Stale numbers only unbalance the shards, never
# drop a test. Classes that share a campaign environment share a shard, whatever their weights. Refresh from green build-shard job
# logs when the shard wall times drift apart, averaging several runs: runner speed alone moved the suite from 16 to 31 minutes.

# Notes: the starter set

Settled 2026-10-07. Canon and context: [LORE.md](../LORE.md). Text inside quote blocks is **player-facing**.

A Note is found in the world. When any member of a charter picks one up, it goes into every member's handbook, unread for each of them ([SPEC.md section 5](../SPEC.md#5-employee-handbook-and-teaching-the-rules)). Each Note's "Where" is the zone it appears in; the exact spot belongs to level design. Notes N01–N11 ship with the vertical slice (M2). The Chairmen's Book and the Ledger are handbook pages, not Notes: see [handbook.md](handbook.md#revisions).

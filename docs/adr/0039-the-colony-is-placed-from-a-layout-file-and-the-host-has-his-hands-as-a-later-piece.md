# The colony is placed from a layout file, on an 80-block pad, and the Host has his hands as a later piece

Carries out the colony part of [ADR 0030](0030-art-direction-decisions.md) and amends [ADR 0016](0016-the-colony-is-built-once-in-code-and-the-conduit-is-set-when-its-chunk-loads.md) (the colony was a table of offsets in code). Issue #244; the user picked layout A of [colony-concepts-2.md](../design/colony-concepts-2.md) and the Host at 10 blocks (2026-10-09).

## Decision

- **The town is structure files and a layout file in the mod's own data.** `tools/colony/town.py` is the source: it writes `data/deepcharter/structure/colony/*.nbt` and `data/deepcharter/colony/layout.json` (`tools/colony/build.py`, checked by `build.py --check` and the Python tests). `ColonyBuilder` still runs once at `SERVER_STARTED` and still flattens the pad and records it first, then places the layout's pieces in order and the terminals on their plinths. The anchors (`ColonyAnchor`) are offsets in the layout, so a data pack that moves a building moves its anchor. Every offset is from the pad's centre, at ground level, X east and Z south.
- **The pad is 80 x 80 and cleared 36 blocks high** (it was 64 and 24): the town needs the hangar 30 blocks west, the hoist house 36 north, the bunkhouse 37 east, and the headframe's beacon 30 up. A test ties the Python and Java numbers. The surface's colony plateau ([ADR 0036](0036-the-surface-is-generated-from-data-by-a-replaced-overworld-dimension.md), flat out to 56 blocks from the origin) still holds the bigger pad: its corners are 55 blocks from the centre.
- **The Host's hands are a piece of their own that waits.** His body is one block display of the sculpture block and his hands another, the same size and place. The layout lists the hands as a `later` piece; the first work order places it (`FounderStatue.restoreHands`), replacing a pair already there. Before, the hands were two copper slabs at fixed offsets.
- **A hands display lasts only while the world says the Host has his hands.** The state is a block in the colony's own chunk data: a `structure_void` where the plinth's shaft has a plate, 3 blocks under his feet, which the work order sets when it places the hands (`FounderStatue.markerPos`). The marker is always 3 blocks under the hands display itself, in the same chunk, so a test can keep a pair and its state in a chunk of its own. When a hands display is tracked (it is placed, or its chunk loads and starts to tick) and the marker is not there, it discards itself (`FounderStatue.init`). Nothing has to find it in a chunk that does not tick, so a pair that outlives its state (a rebuild puts the plate back, a restored backup, a doubled pair after a crash) never shows. The marker loads with the chunk before the entities do, so hands that the world owes survive a save and a reload (`WorkOrdersTest`). I first used the work order's saved data as the state, and chose the block because a test can set a block in any tick, and the test server refuses a swap of saved data that spans ticks.
- **A work order needs a Host that this build placed, and decides it from saved data.** It refuses with `no_statue`, before it takes any ore, unless the colony's saved statue anchor is where the layout puts the Host (`FounderStatue.hasHost`). A colony built before the rebuild has its statue elsewhere. The answer does not depend on which chunks are loaded; an entity query does.
- **The land round the pad is graded to it, once (#375).** Each side's margin is at least 32 blocks and grows with the height gap it must absorb, to a cap of 64 (`ColonyEdge`): a slope of one block a column, so a player walks out on any side. Past the cap the natural relief resumes as a step at the rim. The pad's own surface is the plain's regolith. The grade reads the natural ground, so the colony record says it is done: `ColonySite` is version 2 with `edgeGraded`, and a version 1 record loads with it true, so an older world's land is left alone. A column that holds fluid is not graded, and fluid that would border a cut is sealed with rock.
- **The 30-block headframe and the 10-block Host override the 40 to 60 blocks of [ADR 0030](0030-art-direction-decisions.md) and the art direction:** the user picked them in round 2.
- **A rebuild of an interrupted build takes the block displays of the pad away first.** Displays are entities, found only in chunks that are accessible, so a rebuild in chunks that are not yet ticking can leave the first try's displays beside the new ones. The case is a crash within about a second of the first start; the build does not wait for the chunks. A work order replaces a pair that it finds, and the player who completes it stands at the ore processor, about 9 blocks from the Host, so his chunk ticks.
- **A door is an opening, not a block.** A player walks through a doorway of two blocks, between red jambs under a hazard lintel; a pod's bay is 4 wide and 4 high. `winder_door` and `shutter` are deleted. Mine track has no collision, and an ore car stands on its own length of track.
- **A building's door faces the square or a street, and has a clear line of sight out.** The Lamp and Pick, which faced a blank wall in the old colony, now faces the square across the south street. A test fails for a door with a block in its line.

## Considered Options

- **Keep the pad at 64 and shrink the town.** Rejected: the user picked layout A at the size it was drawn; the hoist house alone is 36 blocks from the square.
- **Place the hands with the body and take them away on a rebuild.** Rejected: a world that has had its hands restored would lose them on a rebuild. The later piece keeps one rule for both.
- **Keep the old buildings as they were and add layout A beside them.** Rejected: the old ruins did not share its scale or language, and the user wants one town.
- **A doorway with a closed door that opens.** Rejected for now: nothing opens it, and a decorative closed door in the way of the spawn is worse than none.

## Consequences

- Old worlds keep the old colony (the pad is built once). A new world gets the town. A work order in an old world refuses to complete, because there is no Host: start a new world, as [PLAYING.md](../PLAYING.md) says. An old build that stopped half way cannot finish under the new layout, and says so: start a new world, or delete the world's `data/deepcharter/colony.dat`.
- The kit holds only what the town uses: the blocks, sculpture pieces, signs and textures that only layouts B, C and D or the other Host sizes used are deleted, and a test keeps it so.
- The layout and the structure files are data a pack can replace. The reload path (a dev command that rebuilds the colony) is not built yet.
- A Minecraft bump re-checks every `.nbt`; `ColonyPlacementTest` places the files and compares every block with the world.

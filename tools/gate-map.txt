# What counts as gate code, and what runs it: the one copy of the gate sweep's mapping rules (#1639; tools/gate-sweep.sh,
# tools/lib/gate-paths.sh, tools/lib/pr-body-checks.sh read it). Edit it when a gate is added, moved or split (#1572 splits
# gradle/gametest.gradle.kts into per-gate files: replace its rule with the new files' `gradle/*gate*` match).
#
# One rule per line: <glob> <actions>. The first rule whose glob matches the path decides (`*` also spans `/`). A path no rule
# matches, or one that matches `ignore`, is not gate code. <actions> are `;`-separated:
#   ignore            not gate code (a gate's own fixture test: it decides nothing about other PRs)
#   script            the `check*` Gradle tasks the file registers by a literal name (`tasks.register("checkX")`,
#                     `tasks.register<T>("checkX")`); a name built at runtime is not seen: list it with `tasks`
#   named             the `check*` tasks of every gradle/*.gradle.kts script that names this file (a
#                     gradle/ file by its name, a config/ file by its directory)
#   tasks T...        these Gradle tasks
#   tool [file]       run `tools/py <file>` (default: the changed file)
#   unittest [file]   run `tools/py -m unittest discover -s tools/tests -p <file's name>` (default: the changed file)
#   shell [file]      run `bash <file>` (default: the changed file)
#   unswept <text>    nothing to run: reported as UNSWEPT with <text> as the manual step
# A gate path whose actions yield nothing runnable is reported UNSWEPT too. tools/tests/gate-sweep.test.sh fails when a Gradle
# script registers a `check*` task that no rule covers.
